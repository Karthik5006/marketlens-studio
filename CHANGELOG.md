# MarketLens Studio 1.0.0

First independent Studio app. Implements the main research, fund holdings/overlap, charting, risk/exposure, alert, IPO/GMP, dividend and FIFO-record workflows described in docs/FEATURES.md, with explicit source and automation limits. Adds a Compose redesign, separate Android identity/storage/upload signing, API 36 targeting, in-app privacy and local deletion controls, and Play/Git preparation.
